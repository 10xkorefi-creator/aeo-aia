How a ChatGPT answer becomes a number on the dashboard

The system does two separate jobs. First it captures: it asks ChatGPT every tracked prompt and saves the answers untouched. Then it reads: it works out the numbers from those saved answers each time, so any figure can be traced back to the answers behind it. The figures below are from the first run, on 17 November 2026.

One real answer, followed all the way through

Prompt P001, third of its four answers, in run R20261117-M1.

  1. Prompt list
    best AI tool for tally prime? is one of the 62 unbranded prompts.
  2. Run queue
    The run creates four requests for it. This is number 3.
  3. Runner
    Sends it to ChatGPT in India through cloro and collects the answer when it is ready.
  4. Raw answer
    Saved as returned. It opens The best AI tool for Tally Prime depends on what you want to automate… and lists links from 10 websites.
  5. Unpack sources
    The 10 websites include tallysolutions.com, taxone.vyapar.com and rikoai.in. None is aiaccountant.com, so cited = no.
  6. Match brands
    The text contains 3. AI Accountant: Automates bill and bank entry workflows. The rule flags it, and the review confirms it is the product and not the generic phrase, so named = yes.
  7. Metrics
    It counts as 1 of the 11 answers that name AiA, out of 248. That is the 4.4% on the dashboard.

Four things this design means in practice

  • The raw answers are never edited. If a rule changes, such as how a brand is matched, every past run can be recalculated from the same answers.
  • The headline uses 248 of the 300 answers. The competitor-comparison and own-brand prompts are captured too, but kept out of the headline so they don't inflate it.
  • The dashboard shows the stored copy. It updates when a run finishes or a review verdict changes, not while a run is still in progress.
  • The first run used the backup script. The n8n workflow does the same steps on a schedule, but it still needs the treg credential added before it can run.
